**Student:** Kartik Hareesh Nayak  
**College:** New Horizon College of Engineering

## Project
An AI-assisted dashboard that estimates the risk of surplus prepared food in a canteen and suggests when staff should assess remaining food for safe redistribution. It supports UN Sustainable Development Goal 12: Responsible Consumption and Production.

## Run locally
1. Install Python 3.10 or later.
2. Open a terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`
5. Open the local URL printed by Streamlit (usually http://localhost:8501).

## Important limitations
The included training data is synthetic and generated for demonstration. The displayed test accuracy is only a software demonstration metric, not validated real-world performance. Before deployment, replace it with consented, verified records from participating kitchens, validate performance across seasons and meal types, and add partner verification, audit logs, and food-safety workflows. The app does not certify food as safe to donate.
